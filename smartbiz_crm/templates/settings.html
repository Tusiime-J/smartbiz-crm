About this SmartBiz CRM MVP.

SmartBiz CRM

Designed as a simple, affordable customer-management tool for Ugandan small and medium-sized businesses, including retail shops, boutiques and salons.

CurrencyUgandan Shilling (UGX)
Application stackPython · Flask · SQLite
DatabaseLocal SQLite file
Prototype statusMVP / demonstration

Current MVP scope

  • Customer records: add, view, edit, search and delete
  • Sales opportunities and pipeline stages
  • Follow-up task creation and completion
  • Dashboard and sales-stage summaries

Planned / not included in this version

  • Secure user registration and login
  • Customer complaint tracking
  • Automated SMS or email reminders
  • CSV and PDF exports
Security note: this MVP does not include user authentication or production security hardening. Run it locally with fictional/demo information only. Do not enter real customer personal data or expose it to the public internet.
